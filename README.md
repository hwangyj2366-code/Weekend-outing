# 주말에 어디가지? (weekend-outing)

아이와 주말에 갈 곳을 빠르게 고르는 한국어 모바일 웹앱이에요.
지도에 저장해 둔 곳을 분류별로 정리하고, 아직 저장하지 않은 인기 장소를 추천해요.

분류(한 줄): **박물관·미술관·고궁 · 과학관 · 체험관·놀이시설(키즈카페 포함) · 자연·공원·바다 · 축제·행사 · 캠핑장 · 음식점·카페 · 숙소 · 시장·거리·쇼핑 · 골프·레저 · 기타**, 설정에서 분류 추가도 돼요. 홈·인기·즐겨찾기에 같은 분류 버튼이 보이고, 홈에 보일 분류는 설정에서 골라요.
이름·네이버 업종명·메모로 자동 분류하고, 가져오기 미리보기나 ✏️에서 바꿀 수 있어요(직접 바꾼 분류는 자동 재분류하지 않아요). ‘한 곳 골라줘’와 인기 ‘전체’는 나들이 분류(박물관~캠핑장)에서만 골라요.

**거리**: 앱을 열 때 위치를 한 번 받아 모든 장소에 직선거리(예: 18km)를 보여줘요. 위치는 이 기기에만 기억하고, 1km 넘게 움직였을 때만 다시 계산해요. 브라우저 위치 기능은 **https 주소(또는 PC의 localhost)**에서만 동작해요.
**지도 보기**: 오픈스트리트맵(키 필요 없음). 리스트 링크·Takeout JSON으로 가져온 곳은 위치가 있고, 예전에 가져온 곳은 설정 → 리스트 [업데이트]로 위치를 채워요.
**아이콘**: 토·일을 콕 찍는 지도 핀 — `npm run icons`로 `scripts/make-icons.mjs`의 도형에서 SVG·PNG를 다시 만들어요.

## 즐겨찾기 가져오기

1. **리스트 링크 붙여넣기 (추천)**
   - 네이버지도: 저장 탭 → 리스트 ⋮ → 리스트 정보 수정에서 **공개** → ⋮ → 공유 → 링크 복사
   - 구글지도: 저장됨 → 리스트 → 공유 → **링크 공유** 켜기 → 링크 복사
   - 붙이면 리스트 전체를 불러와 **미리보기**(새로/이미 저장됨/오류, 분류 변경)를 보여준 뒤 골라서 저장해요.
2. **장소 공유 문구** — 지도 앱에서 장소 → 공유 → 복사한 문구를 여러 개 이어 붙여도 돼요.
3. **안드로이드 공유 메뉴** — 앱을 홈 화면에 설치하면 지도 앱의 공유 메뉴에 ‘주말나들이’가 나타나요(Web Share Target).
4. **파일** — 구글 Takeout ‘저장됨’ CSV / Saved Places.json, 이 앱의 백업 파일.

> 휴대폰 보안상 어떤 앱도 다른 앱(네이버·구글지도)의 즐겨찾기를 직접 읽을 수 없어요. 두 지도 모두 즐겨찾기용 공식 API도 없어서,
> 리스트 링크 읽기는 지도 웹페이지가 쓰는 **비공식 주소**를 서버에서 호출해요(`supabase/functions/_shared/lists.js`). 지도 서비스가 바꾸면 동작하지 않을 수 있고, 그때는 2~4번 방법을 쓰면 돼요.

## ‘인기 있는 곳’ 기준

1. **이번 주말 열리는 축제·행사** — 한국관광공사 행사정보(searchFestival2), 이번 토·일과 기간이 겹치는 행사
2. **실제로 많이 찾아간 곳** — 한국관광공사 ‘관광지별 연관 관광지’(티맵 이동 데이터, 월 단위). 시군구별 연관 순위에 여러 번·높은 순위로 나올수록 점수가 높아요. 카드에 순위와 **기준월** 표시
3. 아이와 가기 어려운 곳(쇼핑·술·숙박 등)과 이미 저장한 곳은 제외
4. 운영 정보(이용시간·쉬는 날·문의)는 국문 관광정보에서 출처·수정일과 함께 표시
5. 연결이 안 되면 **기본 추천** 8곳(서울·경기)

검색량·SNS 화제성은 공식 공개 데이터가 없어 쓰지 않았어요.

공공데이터포털 응답은 호출당 30초 가까이 걸리고 가끔 04(HTTP_ERROR)로 실패해요. 그래서 서버가 인기 장소를 **백그라운드에서 몇 분 동안 만들어 `.cache/`에 저장**하고(12시간마다 갱신), 앱에는 저장본을 바로 보내요. 새로 만들 때는 이전 결과와 합쳐서 목록이 줄지 않게 해요.

## 실행

```bash
npm start
```

- PC: http://localhost:8090 · 휴대폰: 같은 Wi‑Fi에서 터미널에 나오는 `http://192.168.x.x:8090`
- 로컬 서버가 `/api/discover`(인기 장소)와 `/api/import-list`(리스트 읽기)를 함께 제공해요. 인증키는 `.env.local`의 `TOUR_API_KEY`에서 서버만 읽어요.
- 휴대폰에서 `http://192.168…` 로 열면 거리 표시·공유 메뉴·설치는 동작하지 않아요(https 필요). 화면과 즐겨찾기 정리는 그대로 돼요.
- 확인: `npm run selftest` (로직) · `node scripts/probe-tourapi.mjs` (한국관광공사 API 응답 확인, 키는 출력 안 함)

## 배포 (휴대폰에서 어디서나 쓰려면)

구성: **GitHub Pages**(앱 화면, https) + **GitHub Actions**(매일 05시 인기 장소 데이터 만들기) + **Supabase 함수 `import-list`**(지도 리스트 링크 읽기).
인기 장소는 공공데이터 응답이 느려 앱이 직접 부르지 않고, Actions가 미리 만든 `data/discover-<지역>.json`과 전국 행사 `data/events.json`(오늘~다음 달 말)을 사이트와 함께 올려요(이전 배포분과 합쳐 목록이 줄지 않게, 행사 사이트·소개글은 새 행사만 하루 최대 120건 불러요).

1. **GitHub 저장소** — 공개(public) 저장소 `weekend-outing`을 만들고 이 폴더를 `main`으로 올려요.
2. **인증키** — 저장소 Settings → Secrets and variables → Actions → New repository secret: `TOUR_API_KEY` = 공공데이터포털 일반 인증키(Decoding)
3. **Pages 켜기** — Settings → Pages → Build and deployment → Source: **GitHub Actions**. 이후 push할 때마다, 매일 아침 자동 배포돼요(Actions 탭에서 수동 실행도 가능).
4. **Supabase 함수** — 새 프로젝트(리전 **Seoul**)를 만들고:
   ```bash
   npx supabase functions deploy import-list --project-ref <project-ref> --no-verify-jwt
   ```
   (`SUPABASE_ACCESS_TOKEN` 환경 변수 또는 `npx supabase login` 필요)
5. `dist/config.js`의 `importListUrl`을 `https://<project-ref>.supabase.co/functions/v1/import-list`로 바꾸고 push (공개 주소라 넣어도 안전, 키는 넣지 마세요)

배포 주소: `https://hwangyj2366-code.github.io/Weekend-outing/` (저장소 이름이 대문자 W)
배포 전 확인: `node scripts/build-site.mjs site` → `node scripts/serve.mjs 8091 --root site` → `http://localhost:8091/?site` (`?site`를 붙이면 PC에서도 배포 사이트처럼 동작)

> 즐겨찾기는 기기·주소마다 따로 저장돼요. PC(localhost)에 모아 둔 즐겨찾기는 설정 → **백업 파일 저장** 후 휴대폰의 배포 사이트에서 **백업 불러오기**로 옮기거나, 리스트 링크로 다시 가져오면 돼요.

공공데이터포털 활용신청: ‘한국관광공사_국문 관광정보 서비스_GW’, ‘한국관광공사_관광지별 연관 관광지 정보’ (같은 인증키 하나로 둘 다 사용)

## 로그인(선택)

설정 → 👤 계정에서 이메일 링크로 로그인하면 즐겨찾기·제외 목록·가져온 리스트·설정이 Supabase(`weekend_data` 표, 행 보안으로 본인만 접근)에 저장돼 휴대폰·PC에서 같이 써요.
준비: `supabase/migrations/20261111000000_weekend_data.sql`을 SQL Editor에서 실행 → Authentication → URL Configuration에 사이트 주소 추가 → `dist/config.js`의 `supabaseAnonKey`에 publishable(anon) 키 넣기.

## 맛집·인기 보강 키(선택)

GitHub Secrets / `.env.local`: `KAKAO_REST_KEY`, `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` (없으면 그 단계만 건너뛰어요). 네이버 키는 개발자센터가 아니라 네이버 클라우드 NAVER API HUB에서 발급해요(2026년부터 검색 API 신규 발급이 옮겨짐). 네이버 키가 있으면 시군구마다 키즈카페·실내놀이터·체험농장·승마체험·실내동물원도 리뷰 많은 순으로 인기에 더해요.

**✨ 요즘 뜨는 곳** (가볼만한곳 탭의 ✨ 요즘 버튼): ① 네이버 지역 검색 ‘시군구 + 팝업스토어·아이랑 전시·어린이 체험전·아이랑 가볼만한곳’ 리뷰 많은 순, ② 네이버 블로그 ‘시군구 아이랑 가볼만한곳’ 최신 글 100개에 2번 이상 나온 곳(📝 블로그 n), ③ 한국관광공사 관광지 집중률 예측으로 이번 주말 붐빔 70% 이상(👥, 서울·경기·인천, 공공데이터포털에서 `관광지 집중률 방문자 추이 예측 정보` 활용신청 필요). **🎭 아이 공연** (행사 탭): KOPIS 아동공연 중 지금 공연 중인 것 + 지난 7일 예매 순위 — GitHub Secret `KOPIS_KEY`.
모범음식점은 공공데이터포털에서 ‘행정안전부_모범음식점정보 조회서비스’ 활용신청(같은 TOUR_API_KEY). 백년가게는 `data-src/hundred-year.csv`.
