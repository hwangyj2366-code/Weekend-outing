# 주말에 어디가지? (weekend-outing)

아이와 주말에 갈 곳을 빠르게 고르는 한국어 모바일 웹앱이에요.
지도에 저장해 둔 곳을 분류별로 정리하고, 아직 저장하지 않은 인기 장소를 추천해요.

## 화면

| 탭 | 내용 |
|---|---|
| 🏠 홈 | 🎲 한 곳 골라줘(전체/즐겨찾기에서/새로운 곳에서) · 분류·실내/야외 칩 · 지역 선택<br>① 🔥 요즘 인기 있는 곳 (저장 안 한 곳만, ♡로 바로 저장)<br>② ⭐ 내 즐겨찾기에서 추천 — 분류별로 섞어서 보여주기, 🔀 다시 섞기 |
| ⭐ 즐겨찾기 | 오른쪽 위 **＋ 가져오기** · 검색 · 분류 칩(개수) · 분류별 목록 · 🗺 지도 열기 · ✏️ 분류·편집 |
| ⚙️ 설정 | 기본 지역 · 홈에 추천할 분류 · 인기 데이터 상태/다시 불러오기 · 백업 저장/불러오기/모두 지우기 · 휴대폰 설치 안내 |

분류: **아이랑 가볼만한 곳**(박물관·미술관, 어린이과학관·과학관, 체험·놀이, 자연·공원) / **캠핑장** / **여행지**(여행지·명소, 축제·행사) / **음식점·카페** / **숙소** / **기타**(골프·레저 등).
이름·네이버 업종명·메모로 자동 분류하고, 가져오기 미리보기나 ✏️에서 바꿀 수 있어요. ‘한 곳 골라줘’는 기본적으로 아이랑·캠핑장·여행지에서만 골라요.

## 즐겨찾기 가져오기

1. **리스트 링크 붙여넣기 (추천)**
   - 네이버지도: 저장 탭 → 리스트 ⋮ → 리스트 정보 수정에서 **공개** → ⋮ → 공유 → 링크 복사
   - 구글지도: 저장됨 → 리스트 → 공유 → **링크 공유** 켜기 → 링크 복사
   - 붙이면 리스트 전체를 불러와 **미리보기**(새로/이미 저장됨/오류, 분류 변경)를 보여준 뒤 골라서 저장해요.
2. **장소 공유 문구** — 지도 앱에서 장소 → 공유 → 복사한 문구를 여러 개 이어 붙여도 돼요.
3. **안드로이드 공유 메뉴** — 앱을 홈 화면에 설치하면 지도 앱의 공유 메뉴에 ‘주말나들이’가 나타나요(Web Share Target).
4. **파일** — 구글 Takeout ‘저장됨’ CSV / Saved Places.json, 이 앱의 백업 파일.

> 휴대폰 보안상 어떤 앱도 다른 앱(네이버·구글지도)의 즐겨찾기를 직접 읽을 수 없어요. 두 지도 모두 즐겨찾기용 공식 API도 없어서,
> 리스트 링크 읽기는 지도 웹페이지가 쓰는 **비공식 주소**를 서버에서 호출해요(`supabase/functions/_shared/lists.js`). 지도 서비스가 바꾸면 동작하지 않을 수 있고, 그때는 2~4번 방법을 쓰면 돼요.

## ‘인기 있는 곳’ 기준

1. **이번 주말 열리는 축제·행사** — 한국관광공사 행사정보(searchFestival2), 이번 토·일과 기간이 겹치는 행사
2. **실제로 많이 찾아간 곳** — 한국관광공사 ‘관광지별 연관 관광지’(티맵 이동 데이터, 월 단위). 시군구별 연관 순위에 여러 번·높은 순위로 나올수록 점수가 높아요. 카드에 순위와 **기준월** 표시
3. 아이와 가기 어려운 곳(쇼핑·술·숙박 등)과 이미 저장한 곳은 제외
4. 운영 정보(이용시간·쉬는 날·문의)는 국문 관광정보에서 출처·수정일과 함께 표시
5. 연결이 안 되면 **기본 추천** 8곳(서울·경기)

검색량·SNS 화제성은 공식 공개 데이터가 없어 쓰지 않았어요.

## 실행

```bash
npm start
```

- PC: http://localhost:8090 · 휴대폰: 같은 Wi‑Fi에서 터미널에 나오는 `http://192.168.x.x:8090`
- 로컬 서버가 `/api/discover`(인기 장소)와 `/api/import-list`(리스트 읽기)를 함께 제공해요. 인증키는 `.env.local`의 `TOUR_API_KEY`에서 서버만 읽어요.
- 확인: `npm run selftest` (로직) · `node scripts/probe-tourapi.mjs` (한국관광공사 API 응답 확인, 키는 출력 안 함)

## 배포 (휴대폰에서 어디서나 쓰려면)

1. `dist/`를 정적 호스팅에 올리기 — **이전 주소(같은 도메인)**에 올려야 그 브라우저의 v1 즐겨찾기(`weekend-places-v1`)를 자동으로 읽어요. 안드로이드 공유 메뉴·설치는 https 주소에서만 돼요.
2. Supabase 함수 배포
   ```bash
   npx supabase login
   npx supabase link --project-ref <project-ref>
   npx supabase secrets set TOUR_API_KEY=<공공데이터포털 일반 인증키(Decoding)>
   npx supabase functions deploy discover --no-verify-jwt
   npx supabase functions deploy import-list --no-verify-jwt
   ```
3. `dist/config.js`의 `apiBase`를 `https://<project-ref>.supabase.co/functions/v1`로 (공개 주소라 넣어도 안전, 키는 넣지 마세요)

공공데이터포털 활용신청: ‘한국관광공사_국문 관광정보 서비스_GW’, ‘한국관광공사_관광지별 연관 관광지 정보’ (같은 인증키 하나로 둘 다 사용)

## 저장 데이터 (브라우저)

| 키 | 내용 |
|---|---|
| `weekend-places-v2` | 즐겨찾기 `{ version: 2, places: [...] }` |
| `weekend-places-v1` | 첫 버전 데이터 — 읽어서 v2로 옮기고 원본은 남겨 둠 |
| `weekend-settings-v1` | 지역·분류·실내야외·홈 분류 설정 |
| `weekend-live-cache-v1` | 마지막으로 받은 인기 장소(12시간) |

첫 버전 HTML은 `docs/weekend-v1.html`에 보관했어요.
