# 주말에 어디가지? (weekend-outing)

아이와 주말에 갈 곳을 빠르게 고르는 한국어 모바일 웹앱이에요.
지도에 저장해 둔 나들이 장소를 다시 찾고, 아직 저장하지 않은 인기 장소를 발견해요.

- 빌드 없는 정적 웹앱(`dist/`) — 휴대폰 브라우저에서 바로 열고 **홈 화면에 추가**해서 앱처럼 쓸 수 있어요.
- 인기 장소 데이터는 선택 사항: Supabase Edge Function(`supabase/functions/discover`)이 한국관광공사 API를 대신 호출해요. API 키는 서버 비밀값으로만 둡니다.
- 첫 버전 HTML은 `docs/weekend-v1.html`에 보관했어요.

## 실행

```bash
npm start
```

- PC: http://localhost:8090
- 휴대폰: 같은 Wi‑Fi에서 터미널에 표시되는 `http://192.168.x.x:8090` 주소로 접속
- 로직 확인: `npm run selftest`

배포는 `dist/` 폴더를 그대로 정적 호스팅에 올리면 돼요(`.openai/hosting.json`은 이전 호스팅 설정 그대로 복사).
**기존에 쓰던 주소(같은 도메인)에 배포해야** 그 브라우저에 저장된 v1 즐겨찾기(`weekend-places-v1`)를 자동으로 읽어 와요. 브라우저 저장소는 주소(도메인)별로 따로 있기 때문이에요.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 가져오기 | ① 이름+지도 공유 링크 ② 네이버/구글 앱의 공유 문구 여러 개 붙여넣기 ③ 구글 Takeout ‘저장됨’ CSV(여러 파일)·`Saved Places.json` |
| 가져오기 결과 | 추가 수, 이미 저장되어 건너뛴 장소 목록, 오류(줄 번호)·확인 필요 항목 |
| 분류 | 캠핑장·박물관·어린이과학관·체험·놀이·자연·공원 자동 분류 + 카드의 ‘분류·편집’에서 직접 변경(실내/야외, 지역, 메모 포함) |
| 나들이 외 장소 | 골프·맛집·숙소(펜션) 등은 보관하지만 기본 목록·추천에서 제외. ‘골프·맛집·숙소도 보기’로 포함 |
| 새로운 장소 | 이미 저장한 곳 제외, 체크 후 ‘한 번에 저장’. 연결 전에는 **기본 추천** 8곳 |
| 조건 | 지역(기본 서울·경기), 카테고리, 실내·야외, 검색 — 설정은 새로고침 후에도 유지 |
| 한 곳 골라줘 | 현재 탭·조건의 후보에서만 고르고, ‘다른 곳’으로 다시 뽑기. 후보가 없으면 조건 넓히기 버튼 안내 |

## 계정 자동 연동을 하지 않은 이유

- **네이버지도**: 즐겨찾기(MY플레이스)를 내보내거나 읽는 공식 API·내보내기 기능이 없어요. → 공유 링크/공유 문구 붙여넣기로 지원.
- **구글지도**: 저장 목록을 읽는 Maps/Places API는 없어요. Google Data Portability API에 `maps.starred_places` 범위가 있지만 *제한(Restricted) 범위*라 앱 심사가 필요하고, 제공 지역도 제한돼 있어요(한국 사용자 이용 가능 여부 미확인). → Takeout 파일 가져오기로 지원.

## 인기 장소 데이터 연결 (선택)

1. [공공데이터포털](https://www.data.go.kr)에서 아래 두 API를 **활용신청**(둘 다 같은 일반 인증키 사용)
   - 한국관광공사_국문 관광정보 서비스 (KorService2) — 주소·사진·이용시간·쉬는 날
   - 한국관광공사_관광지별 연관 관광지 정보 (TarRlteTarService1) — 인기 근거(티맵 이동 데이터 순위, 기준월)
2. Supabase 프로젝트에 함수 배포
   ```bash
   npx supabase login
   npx supabase link --project-ref <project-ref>
   npx supabase secrets set TOUR_API_KEY=<일반 인증키(Decoding)>
   npm run deploy:function
   ```
3. `dist/config.js`의 `discoverUrl`에 `https://<project-ref>.supabase.co/functions/v1/discover` 입력 (공개 주소라 넣어도 안전, 키는 넣지 마세요)

카드에는 인기 근거(예: “연관 관광지 5개 시군구 순위 등장 · 최고 3위”, 출처, 기준월)와 운영 정보(출처·정보 수정일)가 표시돼요.
서울·경기·인천만 인기 순위를 계산하고, 그 밖의 지역은 관광정보 등록 장소를 “인기 순위 정보 없음”으로 보여줘요.
연결이 안 되면 마지막으로 받은 데이터 또는 기본 추천으로 자동 전환돼요.

> ⚠️ 이 함수는 실제 인증키로 호출해 보지 못했어요. 특히 연관 관광지 API의 응답 필드 이름(`rlteTatsNm`, `rlteRank`, `rlteCtgryLclsNm`, `rlteSignguNm`)과
> 공공데이터포털에 표시된 제공 기간(2024-05~2025-04)은 키 발급 후 확인이 필요해요. 함수는 데이터가 있는 가장 최근 기준월을 자동으로 찾아요.

## 저장 데이터

| 키 | 내용 |
|---|---|
| `weekend-places-v2` | 내 즐겨찾기 `{ version: 2, places: [...] }` |
| `weekend-places-v1` | 첫 버전 데이터 — 읽어서 v2로 옮기고 원본은 남겨 둠 |
| `weekend-settings-v1` | 탭·지역·카테고리·실내야외 선택 |
| `weekend-live-cache-v1` | 마지막으로 받은 인기 장소(12시간) |
